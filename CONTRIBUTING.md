# Contributing to Voiced Rolls

Thank you for your interest in contributing to Voiced Rolls! We welcome all kinds of contributions, from bug reports and feature requests to code contributions and documentation improvements.

## Code Contributions

1. **Fork the Repository**: Create your own fork of the repository.
2. **Create a Branch**: Work on a new branch for your feature or fix.
3. **TypeScript**: All new code should be written in TypeScript.
4. **Follow Linting**: Ensure your code passes linting by running `npm run lint`.
5. **Tests**: If possible, add tests for your changes and ensure existing tests pass with `npm test`.
6. **Built Output**: Do NOT include the `dist/` directory in your pull request. It is ignored by git and built automatically during release.
7. **Submit a Pull Request**: Provide a clear description of your changes and why they are needed.

## Community Guidelines

Please be respectful and constructive in all interactions within the project's community.

## Bug Reports and Feature Requests

Please use the [GitHub Issues](https://github.com/luisjodiez/voiced-rolls/issues) to report bugs or suggest new features.
